## Why
This is the fix itself (contract safe-landing sections 2-3). self_land takes the lease ONCE (int_on; rc 3 returns 3 with the queued line last) and holds it through land, seal and the done fan-out, releasing in its own frame on every exit path. 'Am I the last lane out' is re-read from the board (active/ and ready/ both empty) INSIDE the lease; the handoff-time notice stops deciding the seal. cmd_done takes the now re-entrant lease around its base commit, worktree removal and branch deletion (replace the 'would deadlock' comment with a pointer to the token), releasing only if it took it. cmd_land and cmd_land_express record pre=$(git rev-parse HEAD) before the squash and unwind with git reset -q --hard "$pre" instead of HEAD~1 (printed recovery HINT text may keep HEAD~1). Switch the land_had/ex_had/seal_had checks to int_mine from T-222. Lease stays outermost over the board mutex. Normal-path output and commit graph stay byte-identical.
