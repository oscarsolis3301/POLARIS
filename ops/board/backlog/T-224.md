## Why
Nothing today checks that a done task's files really reached main before done deletes the only copy (the branch). Implement contract safe-landing sections 4-5: helper landed_content_ok <ID> [<ref>] in core.sh (every path in git diff --name-only --no-renames <merge-base> feat/<ID> must have main's blob equal to the feat tip's, deletions absent; stdout the bad paths; rc 0 ok, 1 mismatch, 2 cannot check so proceed silently). In cmd_done, inside the lease and BEFORE the task moves or any branch/worktree is deleted: mismatch means print the one warning line, re-land only the mismatching paths on a fresh wave via the existing wave_on/seal machinery with a subject ending [<ID>] (landed_sha must still find it) and a 're-land' body line, then re-check; a second mismatch prints ONE line naming the task and files, exits 1, keeps the branch and leaves the task where it is. Normal path: no extra commit, no extra output. Drive it with the golden landed-content, cases a-d from the contract: clobbered file re-landed; unfixable mismatch stops and keeps the branch; normal path same commit count and output; dirty tree + ancestor stamp + test_select UNSET behave as before. Update any selftest drill in history.sh/policy.sh whose fixtures now hit the check (fixtures without a feat branch return rc 2 and must stay silent).
