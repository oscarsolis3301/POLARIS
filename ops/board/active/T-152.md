## Why
A self-landing lane leaves its own `feat/<ID>` behind on purpose (worktree-liveness v1.2: never
remove the ground you are standing on). `drift` then calls it CRUFT, `qa` runs `drift --strict`
AFTER the suite, goes red, writes no suite stamp — and the `finish` that follows re-runs the whole
~12-minute suite for a nit `sweep --fix` clears in a second. Observed twice on 2026-09-14; both runs
paid the suite twice for exactly this. It is structural, so the fix lives in the commands: a branch
is cruft only with PROOF that its tip landed (the squash commit's `Landed-from:` trailer, or base
ancestry); a proven branch whose worktree is still live is a lane stepping out, not cruft, and drift
says nothing; a proven idle one is cleared by `qa` before drift ever looks; an unproven one is
reported as diverged and never auto-deleted. `sweep` reuses the same function so there is one
implementation of "safe to delete".

Nothing else in the suite moves: `drill_selfland`, the drift/qa drills and the handover-route golden are all green.
- THE SAFETY ARGUMENT, stated so it can be checked rather than trusted: `feat_tip_landed` never infers anything from the task sitting in `done/`. It reads the branch tip, then looks up a candidate landed commit (the task's `landed:` key, else `landed_sha`'s `[<ID>]` squash on `$BASE`) — and that lookup is NOT the proof. The proof is byte equality between the tip and the `Landed-from:` trailer inside that commit (observe.sh:175-176), or the tip already being an ancestor of `$BASE` (observe.sh:178, the hand-merge case). Every other path falls through to `return 1` (observe.sh:181); refusal is the default and there is no third way out. So a branch is deleted only when its tip sha is literally named by a commit already in `$BASE`, or is itself already in `$BASE` — never because the board says the task is finished.
- both positive paths and the negative one are drilled, so the claim is falsifiable: T-CC/T-QC clear via the trailer read off `landed:`; T-CW clears via the `landed_sha` fallback with no `landed:` key at all; T-CD/T-QD landed once and then took one more commit, so the tip is neither the trailer nor in main — `drift` calls them `CRUFT diverged` and `qa`, `sweep` and `sweep --fix` all leave them standing. That last one is the case that would be catastrophic to get wrong in the permissive direction, and it is asserted in both drills.
